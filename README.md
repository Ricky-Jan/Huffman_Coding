# Huffman Coding Implementation

This repository contains a Huffman Coding text compressor. I created this project primarily for self-learning purposes to deepen my practical understanding of **tree data structures** and **dynamic arrays**. 

Rather than relying on high-level abstractions, this project focuses on understanding how data is structured, linked, and manipulated in memory.

## Current State
* **Dynamic Arrays:** The tree nodes are stored and managed using dynamic arrays (Arena allocation concept), which simplifies memory management and avoids complex pointer lifetimes.
* **Code Generation:** Currently, the binary codes are generated by tracing backwards from each leaf node up to the root, and then reversing the resulting string.

## Planned Optimizations
As part of my ongoing learning process, I plan to refactor and optimize the codebase with the following improvements:

1. **`BinaryHeap` Integration:** 
   I will replace the current linear search for minimum-frequency nodes with a `BinaryHeap` (configured as a Min-Heap). This will significantly improve the time complexity of the tree-building phase from O(N^2) to O(N log N).
2. **Top-Down DFS Traversal:** 
   I will refactor the code generation step to use a Depth-First Search (DFS). By traversing downwards from the root to the leaves, I can build the exact binary paths directly in memory, completely eliminating the need to reverse the strings after generation.
